一、正确渗透通关顺序

ping → scan → nmap → ipinfo → vuln → crack → ssh → sudo → backdoor → shutdown

二、真实有用通关命令

ping、scan、nmap、ipinfo、vuln、crack、ssh、sudo、backdoor、shutdown

三、迷惑无用假命令（凑数干扰）

cd、dir、mkdir、rm、mv、pwd、cat、exit、reboot

四、隐藏秘密命令（help里不显示）

cookienotes ：清除所有Cookie存档，重置全部游戏进度 help -a :看答案（谨慎观看）

五、游戏规则

1、开局输入 help 可以查看全部命令，真假混在一起看不出区别。 2、必须按正确顺序一步步输入，跳步骤会直接报错。 3、每次刷新网页，IP、端口、账号、密码都会随机变化。 4、每过一个阶段自动保存Cookie，下次打开自动接着上次进度玩。 5、必须完整入侵、植入后门后，才可以输入 shutdown 完成关机结局。 6、隐藏命令只能在这里看到，游戏终端里help不会列出。
